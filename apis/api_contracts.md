# API Contracts

This document defines the API contracts used by the Insurance Conversational AI Voice Agent. Each API specifies its purpose, expected request payload, and sample response used for backend integration and testing.

---

## API Summary

| API | Description |
|------|-------------|
| validateUser() | Authenticate customer |
| getPolicyDetails() | Retrieve policy details |
| getClaimsStatus() | Retrieve claim status |
| initiateClaim() | Create a new claim |
| getBenefitsInfo() | Retrieve policy benefits |
| renewPolicy() | Renew policy |
| getProductCoverage() | Retrieve product information |
| onBoardUser() | Register a new customer |
| requestUpdate() | Submit customer update request |
| getRequestStatus() | Retrieve update request status |
| createCase() | Create a support case |
