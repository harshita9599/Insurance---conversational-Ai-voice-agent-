# APIs

This folder contains the API documentation and mock backend responses used by the Insurance Conversational AI Voice Agent.

The APIs simulate backend insurance services for customer authentication, policy management, claims processing, onboarding, update requests, and human escalation.

## Files

| File | Description |
|------|-------------|
| api_contracts.md | API endpoints, request payloads, and response formats |
| mock_api_responses.md | Mock backend responses used during development and testing |

## Available APIs

- validateUser()
- getPolicyDetails()
- getClaimsStatus()
- initiateClaim()
- getBenefitsInfo()
- renewPolicy()
- getProductCoverage()
- onBoardUser()
- requestUpdate()
- getRequestStatus()
- createCase()
