# APIs

This folder contains the API documentation and mock backend responses used by the Insurance Conversational AI Voice Agent.

## Contents

- **api_contracts.md** – API endpoints, request payloads, and response formats.
- **mock_api_responses.md** – Sample backend responses used for testing and demonstration.

## Services Covered

- User Authentication
- Policy Management
- Claims Processing
- Benefits Information
- Product Onboarding
- Customer Update Requests
- Human Escalation
