# User Stories

### Authentication

As a customer, I want to securely verify my identity so that I can safely access my insurance information.

### Policy Inquiry

As a customer, I want to view my policy details so that I understand my coverage.

### Claims

As a customer, I want to check my claim status or create a new claim without waiting for a support representative.

### Update Requests

As a customer, I want to update my personal information so that my policy records remain accurate.

### Human Escalation

As a customer, I want to speak with a live support agent whenever my issue cannot be resolved automatically.
