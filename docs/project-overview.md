# Project Overview

## Objective

The Insurance Conversational AI Voice Agent is designed to automate customer interactions by providing voice-based assistance for insurance-related services. The solution enables customers to securely authenticate themselves, access policy information, manage claims, submit update requests, and connect with a live agent when necessary.

## Key Features

- Secure customer authentication
- Policy inquiry
- Benefits information
- Policy renewal
- Claim status tracking
- New claim creation
- Customer onboarding
- Update request management
- Human agent escalation

## Technology Stack

- Google Dialogflow CX
- Google Cloud Platform
- REST APIs
- Webhooks
- JSON
- BigQuery
