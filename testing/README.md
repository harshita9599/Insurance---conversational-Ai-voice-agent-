# Testing

## Overview

This folder contains the testing documentation for the Insurance Conversational AI Voice Agent. It includes the testing strategy, execution plan, manual test cases, evaluation reports, and performance metrics used to validate the conversational AI solution.

The testing activities focused on verifying authentication, intent recognition, conversation routing, API integration, business workflows, fallback handling, and overall conversational quality.

## Folder Structure

### Manual Testing

- Authentication Test Cases
- Happy Path Test Cases
- Intent Routing Test Cases
- Manual Testing Report

### Evaluations

- Golden Evaluation Report
- Scenario Evaluation Report
- Golden Test Cases
- Evaluation Results
- Intent Accuracy Results

### Metrics

- KPI Dashboard

## Testing Objectives

- Validate authentication workflow
- Verify conversational flows
- Test backend API integration
- Evaluate intent recognition
- Verify policy and claims workflows
- Validate fallback handling
- Measure conversation quality
